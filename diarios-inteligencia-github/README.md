# Diarios de Inteligencia
Sitio editorial estático para GitHub Pages, preparado para el dominio alfonsorustrian.com.

## Publicación
1. Subir el contenido de esta carpeta a la raíz del repositorio de GitHub.
2. Settings → Pages → Deploy from a branch → main → /(root) → Save.
3. Configurar el dominio personalizado `alfonsorustrian.com` en Pages.
4. Configurar los registros DNS en Namecheap según la documentación vigente de GitHub Pages y activar HTTPS cuando esté disponible.

## Antes de publicar
- Sustituir los artículos de muestra por artículos reales y verificados.
- Reemplazar la imagen de referencia de la maqueta por fotografías originales/licenciadas. La imagen actual contiene texto de la maqueta y es provisional.
- Confirmar que el correo de contacto exista y esté habilitado.
- Revisar enlaces, accesibilidad y metadatos.
